# Інструкція: Remnant 2 Overseer 1.0

## Встановлення та запуск

1. На сторінці Releases завантажте архів для своєї системи: Linux x64 (`.tar.gz`) або Windows x64 (`.zip`).
2. Розпакуйте **весь архів** в окрему папку. Не запускайте виконуваний файл безпосередньо з архіву.
3. На Linux відкрийте термінал у розпакованій папці та виконайте `./Start.sh`. Якщо запуск заборонений, виконайте `chmod +x Start.sh RemnantOverseer` і повторіть `./Start.sh`.
4. На Windows відкрийте `RemnantOverseer.exe`. Окремо встановлювати .NET для цих автономних архівів не потрібно.

## Як вибрати свої збереження

1. Відкрийте налаштування (значок шестерні на лівій панелі).
2. Натисніть «Обрати папку» і виберіть папку, в якій **разом** лежать `profile.sav` та `save_0.sav` (або інші файли `save_N.sav`). Можна вибрати `profile.sav` через окрему кнопку або вставити шлях і натиснути «Завантажити».
3. Дочекайтеся повідомлення про завантаження. Якщо гра саме записує файли, повторіть пізніше. Аналізатор працює з тимчасовими копіями файлів.
4. Якщо не знаєте розташування, у Windows перевірте `Saved Games/Remnant2/Steam/<Steam ID>/`; у Linux/Proton шлях зазвичай усередині Steam-бібліотеки `steamapps/compatdata/1282100/pfx/drive_c/users/steamuser/Saved Games/Remnant2/Steam/<Steam ID>/`. Реальний шлях може відрізнятися.

## Персонаж і світ

На вкладці персонажа переглядайте архетипи, параметри та спорядження. На вкладці світу оберіть «Кампанія» або «Пригода», розкрийте локацію та пункт «Де знайти й умови» біля предмета. Доступні пошук, фільтри й перемикач розгортання. Пункт Boss Rush поки лише повідомляє, що цей режим не аналізується.

Видимий запис може означати **можливу нагороду**, для якої потрібні додаткові умови. Володіння предметом не доводить, що його забрали саме в цій генерації. Частину українських текстів перевірено, решта — автоматичний переклад із можливими помилками; для звірки відкрийте англійський оригінал. Наявність іконок залежить від комплекту релізу та може бути неповною.

## Якщо щось не працює

Перевірте, що архів розпакований повністю, вибрано папку з обома типами файлів, а поточний користувач має право їх читати. Якщо не спрацював автоматичний пошук, вкажіть шлях вручну. Не надсилайте свої збереження публічно: вони можуть містити особисті ігрові дані.

Версія 1.0 є пробною: Windows-запуск, усі DLC, стани босів, коректність кожного перекладу та права на поширення окремих ігрових зображень потребують подальшої перевірки.
